# JUSTICE

JUSTICE (JUST Integrated Climate Economy) is an open-source integrated
assessment modelling framework for exploring how modelling assumptions shape
climate policies and their distributive justice outcomes.

    This site documents the restructured JUSTICE (`justice-v2` branch). The
